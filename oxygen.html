HARDWARE USED FOR MEASUREMENT

Blood oxygen saturation can be measured using a wearable physiological monitoring device with an optical pulse oximetry sensor. Such sensors use light-based measurements to estimate the percentage of haemoglobin carrying oxygen.

Astroskin Wearable Physiological Monitoring System

How it works:
A pulse oximetry sensor uses red and infrared light measurements to estimate SpO₂. The wearable sensor provides physiological information for monitoring. This prototype demonstrates the data display and alert workflow; it is not connected to a physical sensor.

NASA DATA & RESEARCH REFERENCES

NASA Open Science Data Repository (OSDR):
NASA's repository provides access to spaceflight-related human physiological, biological and other research data. It is a reference source for developing research-informed astronaut health monitoring systems.

Astroskin wearable reference:
NASA research presentation material identifies Astroskin as a wearable physiological monitoring system capable of measuring oxygen saturation in blood (SpO₂), along with other physiological parameters.

DATA TRANSPARENCY

The dashboard is a research-informed software prototype. NASA OSDR and NASA research presentations are used as references for the monitoring concept and sensor technology. The displayed SpO₂, pulse rate and signal-quality values are simulated interface values. They are not live astronaut measurements, downloaded NASA SpO₂ records or readings from a connected Astroskin device. The High Stimulation profile is a software warning scenario, not a medically validated threshold or diagnosis.
